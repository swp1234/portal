Roblox'ta büyük açık dünya haritaları tasarlarken en büyük zorluk mobil cihaz kısıtlamalarıdır: oyuncuların %60'ından fazlası 3GB altı RAM'e sahip telefonlar kullanır. Haritayı bir kerede yüklemek oyunun anında kapanmasına yol açar.

StreamingEnabled, nesneleri oyuncunun yakınlığına göre dinamik olarak yükler ve kaldırır. Ancak istemci tarafındaki kodların eksik nesneler nedeniyle hata vermemesi için ModelStreamingMode ve RequestStreamAroundAsync doğru yapılandırılmalıdır.

1. StreamingEnabled Çalışma Mantığı: Yarıçap ve Bellek Tasarrufu

Roblox motorunun haritayı dinamik yönetme biçimi:

  • StreamingTargetRadius: Nesnelerin yükleneceği ve çizileceği maksimum stud yarıçapı.
  • StreamingMinRadius: Bellek darlığında dahi asla silinmeyecek çekirdek alan.
  • StreamOutBehavior: Telefon belleği azaldığında uzak blokların bellekten boşaltılması.
  • StreamingPauseMode: Hızlı hareket sırasında harita yetişmezse fiziği güvenle duraklatma.

2. ModelStreamingMode: Model Bütünlüğünü Koruma

Karmaşık modeller için uygun çoğaltma modları:

  • Default: Alt parçalar ayrı ayrı yüklenir ve görsel bozulmalara yol açabilir.
  • Atomic: Model ve tüm parçaları bölünmez tek bir blok olarak aynı anda yüklenir.
  • Persistent: Oyuna girişte yüklenir ve mesafeden bağımsız bellekte kalır (merkez alanlar için).
  • PersistentPerPlayer: Sunucu kodlarıyla belirli oyuncular için özel modelleri sabitleme imkanı.

3. Production Implementation Architecture

StarterPlayer.StarterPlayerScripts.StreamingObjectBinder
-- Streaming-Resilient Tag Binder using CollectionService
local CollectionService = game:GetService("CollectionService")
local Workspace = game:GetService("Workspace")

local TAG_NAME = "InteractiveNPC"

local function onObjectStreamedIn(instance)
    if not instance:IsA("Model") then return end
    
    -- Ensure primary part exists before attaching UI
    local primaryPart = instance.PrimaryPart or instance:WaitForChild("HumanoidRootPart", 5)
    if not primaryPart then return end
    
    print("[Streaming] Interactive object loaded: " .. instance.Name)
    -- Attach billboard prompt or local animation controller
end

local function onObjectStreamedOut(instance)
    print("[Streaming] Interactive object unloaded: " .. instance.Name)
    -- Clean up any active local tweens, highlights, or sound emitters
end

CollectionService:GetInstanceAddedSignal(TAG_NAME):Connect(onObjectStreamedIn)
CollectionService:GetInstanceRemovedSignal(TAG_NAME):Connect(onObjectStreamedOut)

-- Initial sweep for parts already streamed in upon join
for _, obj in ipairs(CollectionService:GetTagged(TAG_NAME)) do
    task.spawn(onObjectStreamedIn, obj)
end

4. Boşluğa Düşmeyi Önleme: RequestStreamAroundAsync

Işınlanma sırasında harita altına düşme sorununu çözme:

  • Boşluk Tehlikesi: Zemin yüklenmeden karakteri taşımak sonsuz düşüşe neden olur.
  • Ön Yükleme Talebi: Sunucudan ışınlanma öncesi player:RequestStreamAroundAsync() çağırın.
  • Geçici Sabitleme: Zemin onaylanana kadar HumanoidRootPart nesnesini Anchored durumunda tutun.

5. Varlık Yönetimi: LOD ve Doku Atlası

Düşük VRAM ile yüksek grafik kalitesi:

  • Mesh LOD: RenderFidelity değerini Performance yaparak uzak detayları azaltın.
  • Doku Atlasları: Dokuları 2048x2048 tek sayfada birleştirerek Draw Call sayısını düşürün.
  • Arka Plan Basitleştirme: Ulaşılamayan dağları hafif düşük poligonlu modellerle değiştirin.

Frequently Asked Questions

StreamingEnabled açılınca eski kodlar neden bozulur?

Uzak nesneler oyuncu yaklaşana kadar istemcide var olmaz. Doğrudan çağrılar nil hatası üretir.

Atomic ile Persistent arasındaki fark nedir?

Atomic uzaktayken modeli tamamen kaldırarak RAM tasarrufu sağlar; Persistent ise bellekte kalıcıdır.

Bu sistem mobilde çökmeyi nasıl önler?

Bellekte sadece birkaç yüz stud mesafedeki nesneleri tutarak RAM kullanımını 800MB altında sınırlar.

Sunucu istemciden silinmiş parçalara erişebilir mi?

Evet! Sunucu her zaman tüm haritayı eksiksiz olarak belleğinde muhafaza eder.
