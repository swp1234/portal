A responsividade em jogos multiplayer depende da latência de rede. Disparar RemoteEvents individuais para cada tiro ou passo satura os buffers, gerando descompasso e desespero em conexões móveis.

Com a biblioteca nativa `buffer` do Luau e a classe `UnreliableRemoteEvent`, você ganha controle binário sobre o tráfego de dados. A serialização compacta permite criar experiências com 100 jogadores e latência mínima.

1. Orçamento de Replicação e Limites de Pacotes

Entenda os limites físicos do motor de rede do Roblox:

  • A Regra dos 50 KB/s: Ultrapassar 50 KB/s por cliente introduz latência sintética e acúmulo de dados em redes celulares.
  • Sobrecarga de Cabeçalhos: Cada chamada de RemoteEvent adiciona ~9 bytes de metadados. A 60 FPS, são 500 bytes/s gastos só em cabeçalhos.
  • Descarte pelo Servidor: Clientes que disparam centenas de eventos por quadro têm seus pacotes descartados pelo servidor.

2. RemoteEvent vs. UnreliableRemoteEvent

Escolhendo o protocolo de transporte adequado:

  • RemoteEvent (Confiável): Garante entrega e ordem exata. Essencial para compras, trocas, dano de vida e início de rodadas.
  • UnreliableRemoteEvent (Rápido, UDP): Descarta pacotes atrasados sem reenvio. Perfeito para efeitos visuais, áudio e coordenadas contínuas.
  • Sem Gargalo de Reenvio: Evita o congestionamento em massa que ocorre após pequenas quedas de sinal Wi-Fi.

3. Serialização Binária com Buffer do Luau

Transformando tabelas pesadas em fluxos de bytes ultraleves:

  • Desperdício de Tabelas: { x = 120.5, y = 14.2, z = -80.1, id = 42 } consome mais de 40 bytes devido aos nomes dos campos.
  • Buffer de 7 Bytes: Com buffer.create(7), três números de 16 bits e um byte de 8 bits reduzem o uso de dados em 82%.
  • Empacotamento de Bits: Vários valores booleanos (correr, agachar, mirar) são compactados em um único byte de máscara.
ReplicatedStorage.Network.PacketCompressor
-- Módulo de serialização binária para replicação
local PacketCompressor = {}

function PacketCompressor.serialize(posX, posY, posZ, flags)
    local buf = buffer.create(7)
    buffer.writei16(buf, 0, math.clamp(math.round(posX * 10), -32768, 32767))
    buffer.writei16(buf, 2, math.clamp(math.round(posY * 10), -32768, 32767))
    buffer.writei16(buf, 4, math.clamp(math.round(posZ * 10), -32768, 32767))
    local mask = 0
    if flags.isSprinting then mask = bit32.bor(mask, 1) end
    if flags.isCrouching then mask = bit32.bor(mask, 2) end
    if flags.isAiming    then mask = bit32.bor(mask, 4) end
    if flags.isGrounded  then mask = bit32.bor(mask, 8) end
    buffer.writeu8(buf, 6, mask)
    return buf
end

function PacketCompressor.deserialize(buf)
    local posX = buffer.readi16(buf, 0) / 10
    local posY = buffer.readi16(buf, 2) / 10
    local posZ = buffer.readi16(buf, 4) / 10
    local mask = buffer.readu8(buf, 6)
    local flags = {
        isSprinting = bit32.band(mask, 1) ~= 0,
        isCrouching = bit32.band(mask, 2) ~= 0,
        isAiming    = bit32.band(mask, 4) ~= 0,
        isGrounded  = bit32.band(mask, 8) ~= 0,
    }
    return posX, posY, posZ, flags
end

return PacketCompressor

4. Agrupamento de Pacotes e Controle de Frequência

Juntando microeventos em quadros regulares de rede:

  • Frequência Fixa de 20 Hz: Não envie eventos no RenderStepped. Acumule os dados e envie a cada 50 ms.
  • Envio em Lote: Vários tiros ou ações no mesmo quadro devem ser consolidados em um único buffer.
  • Compressão Delta: Envie apenas a diferença em relação ao estado anterior em vez de coordenadas absolutas.

5. Validação no Servidor, Predição e Reconciliação

Garantindo segurança contra trapaças e resposta imediata:

  • Predição do Cliente: Movimentos e efeitos visuais são executados localmente sem esperar a resposta do servidor.
  • Autoridade do Servidor: O servidor deve verificar alcance, cadência e velocidade sem confiar no cliente.
  • Compensação de Lag: O servidor mantém um histórico das posições dos jogadores e retrocede o tempo para validar acertos justos.

Frequently Asked Questions

Qual a diferença entre RemoteEvent e UnreliableRemoteEvent?

RemoteEvent garante entrega ordenada e retransmissão de perdas. UnreliableRemoteEvent não reenvia pacotes perdidos, funcionando como UDP, ideal para telemetria e efeitos.

Como os buffers do Luau reduzem o lag de rede?

Eles removem nomes de chaves e estruturas de tabelas, transmitindo bytes brutos compactos e reduzindo o consumo de banda em mais de 80%.

Por que não disparar remotos dentro do RenderStepped?

Porque o RenderStepped opera na taxa de atualização da tela (até 144Hz+), estourando o limite de 50 KB/s da engine do Roblox.

O que é compensação de lag no servidor?

É o mecanismo onde o servidor mantém o histórico de posições dos jogadores e retrocede o tempo para validar acertos de tiro com precisão.
