Criar um plugin comercial exige o domínio de APIs exclusivas do Studio: DockWidgetPluginGui para painéis acopláveis, ChangeHistoryService para manter o Ctrl+Z funcionando perfeitamente e Selection API. Este guia explica todo o processo.

Vantagem do Tooling: Um plugin com 5.000 usuários ativos gera renda passiva consistente sem custos com servidores online ou manutenção pesada.

1. Arquitetura e Permissões de Plugins no Studio

Plugins rodam com permissões avançadas no Roblox Studio:

  • Contexto de Execução: Execução local no cliente do Studio com acesso a propriedades internas e seleção.
  • Plugins Locais: Salve scripts em %localappdata%\Roblox\Plugins para testar instantaneamente sem enviar para a web.
  • Permissões de Segurança: Requisições HTTP externas exigem confirmação expressa do usuário.

2. Criando Painéis Acopláveis com DockWidgetPluginGui

Construa interfaces que se integram perfeitamente às abas do Studio:

  • DockWidgetPluginGuiInfo: Define estado inicial (flutuante, lateral) e dimensões mínimas da janela.
  • Cores com StudioTheme: Consulte settings().Studio.Theme para adaptar o visual aos modos Claro e Escuro.
  • Layout Adaptável: Use UIListLayout para manter o alinhamento ao redimensionar o painel.

3. Desfazer Seguro com ChangeHistoryService

O erro mais comum de iniciantes é corromper o histórico de Ctrl+Z do desenvolvedor:

  • Gravar Waypoint: Chame ChangeHistoryService:SetWaypoint() logo após alterar qualquer objeto.
  • Operações Atômicas: Junte todas as ações para que um único Ctrl+Z reverta todo o trabalho do plugin.
  • Selection API: Modifique com segurança apenas os itens selecionados usando Selection:Get().

4. Código Completo: Otimizador de Malhas por Lote

Script funcional que cria um botão, abre um painel e otimiza as peças selecionadas:

Script Completo do Plugin (Toolbar & DockWidget)
local ChangeHistoryService = game:GetService("ChangeHistoryService")
local Selection = game:GetService("Selection")

local toolbar = plugin:CreateToolbar("Optimization Tools")
local button = toolbar:CreateButton("Optimizer", "Open Batch Part Optimizer", "rbxassetid://4458901886")

local widgetInfo = DockWidgetPluginGuiInfo.new(
    Enum.InitialDockState.Float,
    false, false, 260, 180, 200, 140
)

local widget = plugin:CreateDockWidgetPluginGui("BatchOptimizerGui", widgetInfo)
widget.Title = "Mesh Optimizer"

local btnOptimize = Instance.new("TextButton")
btnOptimize.Size = UDim2.new(1, -20, 0, 44)
btnOptimize.Position = UDim2.new(0, 10, 0, 10)
btnOptimize.Text = "Otimizar Pecas Selecionadas"
btnOptimize.BackgroundColor3 = Color3.fromRGB(16, 185, 129)
btnOptimize.TextColor3 = Color3.fromRGB(255, 255, 255)
btnOptimize.Parent = widget

button.Click:Connect(function()
    widget.Enabled = not widget.Enabled
end)

btnOptimize.MouseButton1Click:Connect(function()
    local selected = Selection:Get()
    local count = 0
    for _, obj in ipairs(selected) do
        if obj:IsA("BasePart") then
            obj.CastShadow = false
            if obj:IsA("MeshPart") then
                obj.CollisionFidelity = Enum.CollisionFidelity.Box
            end
            count = count + 1
        end
    end
    ChangeHistoryService:SetWaypoint("Optimized " .. count .. " Parts")
end)

Como funciona: Adiciona um botão na barra de ferramentas, abre uma janela flutuante e otimiza sombras e colisões com um ponto de restauração seguro.

Perguntas Frequentes (Plugins Roblox Studio 2026)

Como testar um plugin no Studio sem precisar publicar?

Salve o arquivo diretamente na pasta local de plugins do Studio. Ele será executado automaticamente.

É possível vender plugins por dinheiro de verdade (dólares)?

Sim, criadores com identidade verificada podem precificar plugins em dólares na Creator Store.

Por que o ChangeHistoryService é essencial?

Ele impede que o plugin destrua o histórico de Ctrl+Z do desenvolvedor que está utilizando a ferramenta.

Como deixar o visual adaptado aos temas Claro e Escuro?

Utilize settings().Studio.Theme:GetColor() para obter as cores nativas do sistema.
