Mientras la mayoría de los desarrolladores crean experiencias para jugadores, un grupo selecto de programadores genera ingresos constantes vendiendo herramientas profesionales para otros creadores en la Roblox Creator Store.

Construir un plugin comercial requiere dominar APIs exclusivas de Studio: DockWidgetPluginGui para ventanas acoplables, ChangeHistoryService para un deshacer/rehacer (Ctrl+Z) impecable, y Selection API. Esta guía explica el proceso paso a paso.

Modelo de Negocio: Un plugin con 5.000 usuarios activos genera ingresos pasivos recurrentes sin costes de servidores ni mantenimiento continuo.

1. Ciclo de Vida y Permisos del Plugin

Los plugins se ejecutan con permisos avanzados en Studio:

  • Contexto de Ejecución: Se ejecutan localmente en Studio con acceso a la jerarquía del proyecto y selección.
  • Plugins Locales: Guarda scripts en %localappdata%\Roblox\Plugins para recarga en caliente instantánea.
  • Permisos de Seguridad: Solicitudes HTTP requieren confirmación expresa del usuario mediante diálogo de seguridad.

2. Paneles Acoplables con DockWidgetPluginGui

Crea interfaces nativas que se acoplan a los paneles de Studio:

  • Configuración de Ventana: Define posición inicial (flotante, lateral) y dimensiones mínimas.
  • Soporte Tema Claro/Oscuro: Usa settings().Studio.Theme para adaptar colores automáticamente.
  • Diseño Adaptable: Emplea UIListLayout para que la interfaz se ajuste al cambiar el tamaño del panel.

3. Deshacer Seguro con ChangeHistoryService

Un mal plugin rompe el historial de Ctrl+Z del usuario:

  • Registrar Waypoints: Llama siempre a ChangeHistoryService:SetWaypoint() tras realizar cambios.
  • Operaciones Atómicas: Agrupa transformaciones para que un solo Ctrl+Z revierta toda la acción del plugin.
  • Selection API: Modifica únicamente los objetos seleccionados mediante Selection:Get().

4. Código Completo: Optimizador de Partes por Lotes

Script funcional que crea un botón, ventana y optimiza mallas seleccionadas:

Script Completo del Plugin (Toolbar & DockWidget)
local ChangeHistoryService = game:GetService("ChangeHistoryService")
local Selection = game:GetService("Selection")

local toolbar = plugin:CreateToolbar("Optimization Tools")
local button = toolbar:CreateButton("Optimizer", "Open Batch Part Optimizer", "rbxassetid://4458901886")

local widgetInfo = DockWidgetPluginGuiInfo.new(
    Enum.InitialDockState.Float,
    false, false, 260, 180, 200, 140
)

local widget = plugin:CreateDockWidgetPluginGui("BatchOptimizerGui", widgetInfo)
widget.Title = "Mesh Optimizer"

local btnOptimize = Instance.new("TextButton")
btnOptimize.Size = UDim2.new(1, -20, 0, 44)
btnOptimize.Position = UDim2.new(0, 10, 0, 10)
btnOptimize.Text = "Optimizar Partes Seleccionadas"
btnOptimize.BackgroundColor3 = Color3.fromRGB(16, 185, 129)
btnOptimize.TextColor3 = Color3.fromRGB(255, 255, 255)
btnOptimize.Parent = widget

button.Click:Connect(function()
    widget.Enabled = not widget.Enabled
end)

btnOptimize.MouseButton1Click:Connect(function()
    local selected = Selection:Get()
    local count = 0
    for _, obj in ipairs(selected) do
        if obj:IsA("BasePart") then
            obj.CastShadow = false
            if obj:IsA("MeshPart") then
                obj.CollisionFidelity = Enum.CollisionFidelity.Box
            end
            count = count + 1
        end
    end
    ChangeHistoryService:SetWaypoint("Optimized " .. count .. " Parts")
end)

Cómo funciona: Crea un botón en la barra superior, despliega una ventana acoplable y optimiza mallas con un punto de restauración seguro.

Preguntas Frecuentes (Plugins Roblox Studio 2026)

¿Cómo probar un plugin en Studio sin publicarlo en la web?

Guarda el archivo en la carpeta local de plugins de Studio (Plugins > Abrir carpeta de plugins). Se cargará al instante.

¿Se pueden vender plugins por dinero real (dólares)?

Sí, los desarrolladores verificados pueden vender plugins en dólares en la Creator Store.

¿Por qué es indispensable ChangeHistoryService?

Permite que el usuario deshaga los cambios del plugin con Ctrl+Z sin romper su trabajo previo.

¿Cómo adaptar la interfaz al modo claro y oscuro?

Obtén los colores oficiales con settings().Studio.Theme:GetColor().
