Dans les productions Roblox modernes, la souplesse physique des personnages distingue les titres de qualité. Les animations figées peinent à s'adapter aux escaliers ou aux rochers, donnant l'impression de pieds flottants ou ensevelis.

Le système d'animation contemporain intègre la cinématique inverse native avec IKControl. En associant détection de sol par raycast, pistes mélangées par pondération et orientation du regard, vous obtiendrez des mouvements fluides dignes des meilleurs studios.

1. Pipeline Moderne: L'Instance Animator & Priorités

Gestion rigoureuse des pistes squelettiques en Luau:

  • L'Instance Animator: Bannissez le vieux Humanoid:LoadAnimation(). Chargez toujours vos pistes via l'Animator pour une synchronisation réseau infaillible.
  • Priorités d'Animation: Classez vos pistes par ordre hiérarchique (Core, Idle, Movement, Action). Une action de recharge sur Action anime les bras sans stopper la course des jambes.
  • Fondu & Poids: Utilisez track:Play(fadeTime, weight) pour enchaîner marche, trot et sprint sans rupture brutale.

2. Architecture de Cinématique Inverse avec IKControl

Calcul automatique des articulations vers une cible:

  • Propriétés Clés: Définit Type (LookAt, Position, Transform), EndEffector (ex. LeftFoot), Target et ChainRoot (LeftUpperLeg).
  • Contrainte Pole: Placez un repère Pole en avant du genou pour éviter toute flexion anormale vers l'arrière.
  • Modulation du Weight: Faites varier la valeur Weight (0 à 1) pour engager le calcul dynamique uniquement au contact du sol.

3. Pose de Pied Procédurale & Ajustement de Pente

Ancrer les semelles sur les marches et les pierres:

  • Raycast Vertical: Projetez un rayon vers le bas depuis chaque hanche pour obtenir la distance et le vecteur normal du sol.
  • Positionnement de Cible: Placez l'attachment cible au point d'impact en ajoutant l'épaisseur de la semelle.
  • Inclinaison de Cheville: Orientez le pied selon la normale du sol pour que la chaussure repose à plat sur la pente.

-- Contrôleur de Pose de Pied Procédurale avec IKControl
local RunService = game:GetService("RunService")
local FootIK = {}
FootIK.__index = FootIK

function FootIK.new(character)
    local self = setmetatable({}, FootIK)
    self.Char = character
    self.Humanoid = character:WaitForChild("Humanoid")
    self.RootPart = character:WaitForChild("HumanoidRootPart")

    local leftIK = Instance.new("IKControl")
    leftIK.Name = "LeftFootIK"
    leftIK.Type = Enum.IKControlType.Transform
    leftIK.EndEffector = character:WaitForChild("LeftFoot")
    leftIK.ChainRoot = character:WaitForChild("LeftUpperLeg")

    local leftTarget = Instance.new("Attachment")
    leftTarget.Name = "LeftIKTarget"
    leftTarget.Parent = workspace.Terrain
    leftIK.Target = leftTarget
    leftIK.Parent = self.Humanoid

    self.LeftIK = leftIK
    self.LeftTarget = leftTarget
    return self
end

function FootIK:Update(dt)
    if self.Humanoid.FloorMaterial == Enum.Material.Air then
        self.LeftIK.Weight = 0
        return
    end

    local rayOrigin = self.Char.LeftUpperLeg.Position
    local rayDirection = Vector3.new(0, -3.5, 0)
    local rayParams = RaycastParams.new()
    rayParams.FilterDescendantsInstances = {self.Char}
    rayParams.FilterType = Enum.RaycastFilterType.Exclude

    local result = workspace:Raycast(rayOrigin, rayDirection, rayParams)
    if result then
        self.LeftTarget.WorldPosition = result.Position + Vector3.new(0, 0.4, 0)
        self.LeftIK.Weight = 0.8
    else
        self.LeftIK.Weight = 0
    end
end

return FootIK

4. Suivi Dynamique du Regard (Look-At)

Orienter la tête vers la caméra ou les personnages proches:

  • Regard Caméra: Associez un IKControl LookAt à la tête et liez la cible au focus caméra pour un avatar expressif.
  • Limites Angulaires: Verrouillez la rotation à environ 70° horizontalement et 45° verticalement pour éviter les torsions improbables.
  • Amortissement Fluide: Interpolez la position avec Lerp pour supprimer toute saccade artificielle.

5. Optimisation Mobile & Gestion des Ressources

Préserver 60 FPS sur les serveurs très peuplés:

  • Calcul Côté Client: Exécutez l'IK procédural dans RenderStepped sur chaque machine cliente.
  • Culling LOD: Désactivez IKControl sur les personnages situés à plus de 60 studs de distance.
  • Nettoyage Mémoire: Détruisez les attachments et déconnectez les boucles quand l'avatar est vaincu.

Frequently Asked Questions

Pourquoi privilégier Animator:LoadAnimation à Humanoid:LoadAnimation ?

La méthode sur Humanoid est dépréciée et perturbe la réplication multijoueur. L'Animator gère le réseau de manière native et fluide.

Quel est l'avantage d'IKControl par rapport aux scripts CFrame manuels ?

IKControl s'exécute dans le cœur C++ de Roblox, offrant une rapidité inégalée et une fusion naturelle avec les pistes d'animation.

Comment empêcher les genoux de plier à l'envers ?

Associez un repère Pole placé légèrement devant l'articulation pour contraindre l'angle de courbure.

Où faire tourner l'IK de marche : serveur ou client ?

Toujours sur le client via RenderStepped pour garantir une réactivité immédiate sans saturer la bande passante.

Comment couper l'IK pendant un saut ?

Vérifiez Humanoid.FloorMaterial : dès que le joueur est en l'air, réduisez instantanément le Weight de l'IKControl à 0.
