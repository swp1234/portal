1. 二叉空间分割（BSP）实现无重叠房间布局

均匀划分地图空间的递归几何算法：

  • 递归子树分割： 将初始矩形区域按随机比例（0.4至0.6）水平或垂直切分，直至叶节点达到目标房间规格。
  • 长宽比与安全边距约束： 强制限制房间比例在1:1到1:2.5之间并留出边距，杜绝狭长如铅笔般的畸形房间。
  • 叶节点内切成房： 房间完全内切于叶节点独立包围盒中，无需昂贵的全图碰撞检测即可从根本上规避房间重叠。

2. 纯天然走廊：Delaunay三角剖分与最小生成树（MST）

兼顾探索捷径与全图连通的通道拓扑学：

  • 质心点云构建： 提取所有房间中心坐标，生成平面2D Delaunay三角剖分网，捕获全部潜在相邻路径。
  • Prim算法提取最小生成树： 剔除冗余路径，确保所有房间以最短总路径实现100%全连通且无死路。
  • 循环环路再注入（15%冗余边）： 随机复原部分被剔除的三角边，打破单一线性枯燥路线，提供分支与回头路。

3. 网格化走廊开凿与自动贴图拼接

将抽象拓扑图转化为物理3D游戏场景：

  • 直角折线连接： 在相连房间之间生成直角L型或S型走廊，并在房间外墙接触点开辟门框。
  • 4-Bit自动寻砖（Autotiling）： 根据上下左右相邻网格状态，自动匹配直墙、阴阳转角与十字路口模型。
  • 几何体合并减面： 通过Welded Model或EditableMesh将通道地块合并为单体模型，减少90%的实体Part数量。

-- BSP二叉空间分割房间树节点模块
local BSPNode = {}
BSPNode.__index = BSPNode

function BSPNode.new(x, z, width, depth)
    local self = setmetatable({}, BSPNode)
    self.X, self.Z = x, z
    self.Width, self.Depth = width, depth
    self.LeftChild = nil
    self.RightChild = nil
    self.Room = nil
    return self
end

function BSPNode:Split(minSize)
    if self.LeftChild or self.RightChild then return false end
    local splitHorizontal = math.random() > 0.5
    if self.Width > self.Depth and (self.Width / self.Depth) >= 1.25 then
        splitHorizontal = false
    elseif self.Depth > self.Width and (self.Depth / self.Width) >= 1.25 then
        splitHorizontal = true
    end
    local maxDimension = (splitHorizontal and self.Depth or self.Width) - minSize
    if maxDimension <= minSize then return false end
    local splitPos = math.random(minSize, maxDimension)
    if splitHorizontal then
        self.LeftChild = BSPNode.new(self.X, self.Z, self.Width, splitPos)
        self.RightChild = BSPNode.new(self.X, self.Z + splitPos, self.Width, self.Depth - splitPos)
    else
        self.LeftChild = BSPNode.new(self.X, self.Z, splitPos, self.Depth)
        self.RightChild = BSPNode.new(self.X + splitPos, self.Z, self.Width - splitPos, self.Depth)
    end
    return true
end

return BSPNode

4. 内存裁剪与StreamingEnabled分块流式架构

保障2GB内存手机设备流畅运行超大复杂地牢：

  • ModelStreamingMode.Atomic： 将单个房间及相连走廊设为原子级加载模型，杜绝地板缺块导致的虚空坠落。
  • 64x64 studs空间扇区分块： 对距离玩家视野较远的扇区暂停物理碰撞解算，大幅释放CPU算力。
  • 动态遮挡剔除（Occlusion Culling）： 房间门廊设计视野盲区，引导Roblox渲染引擎跳过未被直视的暗室。

5. 随机数种子（Seed）同步与服务端权威生成

极低带宽消耗下的多端同步与防作弊机制：

  • 确定性伪随机种子同步： 服务端仅向下分发一个32位整数Seed，各客户端本地自主推导生成完全一致的地形。
  • 服务端掌控关键实体： 装饰性地板在本地生成，但怪物仇恨、宝箱掉落与机关陷阱严格在服务端判定。
  • 动态NavMesh寻路适配： 为生成的通道地块注入PathfindingModifier，确保NPC怪物能自动规避深坑精准追击。

Frequently Asked Questions

相比纯随机散布，为什么BSP是更好的地牢生成方案？

纯随机容易导致房间碰撞和地图大面积空白。BSP通过空间递归细分，数学上保证房间绝对互不相交且全图分布均匀。

Delaunay三角剖分与最小生成树（MST）如何配合？

Delaunay建立自然的邻居连线网，MST从中提取无孤立房间的最短主干道，再回补15%多余边即可形成完美的探索回环。

StreamingEnabled对大型地牢有什么实质帮助？

它能根据玩家位置动态加载和卸载房间，使拥有数百间房屋的超级地牢也能在低配手机上以极低内存平稳运行。

如何实现多端地图完全一致且无网络卡顿？

通过共享相同的伪随机数种子（Seed），客户端无需下载巨量场景数据即可在本地瞬间算出一模一样的地牢。
