Responsivitas dalam game kompetitif Roblox sangat bergantung pada jaringan. Memanggil RemoteEvent untuk setiap peluru atau langkah kaki membuat buffer penuh, memicu desinkronisasi parah pada koneksi seluler.

Dengan pustaka `buffer` Luau dan kelas `UnreliableRemoteEvent`, developer memiliki kendali biner penuh atas lalu lintas data. Serialisasi kompak memungkinkan server 100 pemain berjalan sangat lancar dengan bandwidth minimal.

1. Anggaran Replikasi & Batas Paket Jaringan

Batasan teknis pada mesin jaringan Roblox:

  • Aturan 50 KB/s: Melebihi 50 KB/s per client memicu latensi buatan dan penumpukan data pada perangkat seluler.
  • Overhead Header: Setiap panggilan RemoteEvent menambah sekitar 9 byte metadata. Pada 60 FPS, 500 byte/s terbuang hanya untuk header.
  • Pembatasan Server: Server akan membuang paket dari client yang mengirim ratusan permintaan per frame.

2. RemoteEvent vs. UnreliableRemoteEvent

Memilih protokol transportasi yang tepat:

  • RemoteEvent (Mirip TCP): Menjamin pengiriman dan urutan data. Sangat penting untuk pembelian, transaksi, damage, dan putaran permainan.
  • UnreliableRemoteEvent (Mirip UDP): Membuang paket yang terlambat tanpa kirim ulang. Cocok untuk visual peluru, partikel, audio, dan telemetri.
  • Bebas Hambatan: Mencegah penumpukan data yang biasanya terjadi saat sinyal WiFi melemah sesaat.

3. Serialisasi Biner dengan Luau Buffer

Mengompresi tabel besar menjadi aliran biner ringkas:

  • Pemborosan Tabel: { x = 120.5, y = 14.2, z = -80.1, id = 42 } menghabiskan lebih dari 40 byte karena nama kunci teks.
  • Struktur 7 Byte: Dengan buffer.create(7), tiga angka 16-bit dan satu byte 8-bit menghemat 82% ukuran data.
  • Bitpacking: Nilai boolean (lari, jongkok, bidik) dipadatkan ke dalam satu byte bitmask.

-- Modul serialisasi biner untuk sinkronisasi input
local PacketCompressor = {}

function PacketCompressor.serialize(posX, posY, posZ, flags)
    local buf = buffer.create(7)
    buffer.writei16(buf, 0, math.clamp(math.round(posX * 10), -32768, 32767))
    buffer.writei16(buf, 2, math.clamp(math.round(posY * 10), -32768, 32767))
    buffer.writei16(buf, 4, math.clamp(math.round(posZ * 10), -32768, 32767))
    local mask = 0
    if flags.isSprinting then mask = bit32.bor(mask, 1) end
    if flags.isCrouching then mask = bit32.bor(mask, 2) end
    if flags.isAiming    then mask = bit32.bor(mask, 4) end
    if flags.isGrounded  then mask = bit32.bor(mask, 8) end
    buffer.writeu8(buf, 6, mask)
    return buf
end

function PacketCompressor.deserialize(buf)
    local posX = buffer.readi16(buf, 0) / 10
    local posY = buffer.readi16(buf, 2) / 10
    local posZ = buffer.readi16(buf, 4) / 10
    local mask = buffer.readu8(buf, 6)
    local flags = {
        isSprinting = bit32.band(mask, 1) ~= 0,
        isCrouching = bit32.band(mask, 2) ~= 0,
        isAiming    = bit32.band(mask, 4) ~= 0,
        isGrounded  = bit32.band(mask, 8) ~= 0,
    }
    return posX, posY, posZ, flags
end

return PacketCompressor

4. Pengemasan Paket dan Pembatasan Frekuensi

Menggabungkan mikro-event ke dalam interval waktu tetap:

  • Frekuensi Stabil 20 Hz: Jangan panggil remote di dalam RenderStepped. Kumpulkan data dan kirim setiap 50 ms.
  • Pengiriman Kolektif: Gabungkan beberapa tembakan dalam satu frame ke dalam satu buffer pengiriman.
  • Kompresi Delta: Kirimkan selisih perubahan posisi dari status sebelumnya, bukan koordinat absolut.

5. Validasi Server, Prediksi Client & Kompensasi Lag

Menjaga keamanan tanpa mengorbankan kelancaran bermain:

  • Prediksi Client: Gerakan dan efek visual langsung dimainkan di client tanpa menunggu konfirmasi server.
  • Otoritas Server: Server wajib memeriksa kecepatan, batas tembakan, dan garis pandang secara mandiri.
  • Kompensasi Lag: Server menyimpan riwayat posisi pemain selama 1000 ms dan memutar balik waktu saat tembakan terjadi.

Frequently Asked Questions

Apa perbedaan utama RemoteEvent dan UnreliableRemoteEvent?

RemoteEvent menjamin pengiriman dan urutan dengan kirim ulang jika hilang. UnreliableRemoteEvent bekerja seperti UDP, langsung membuang paket yang terlambat tanpa kirim ulang, sangat hemat untuk efek dan telemetri.

Bagaimana Luau Buffer memangkas lag jaringan?

Buffer membuang teks nama kunci pada tabel dan mengirimkan biner murni, memangkas ukuran paket lebih dari 80%.

Mengapa tidak boleh memanggil RemoteEvent di RenderStepped?

RenderStepped berjalan mengikuti refresh layar (hingga 144Hz+). Mengirim data setiap frame langsung melampaui batas 50 KB/s dan menimbulkan lag parah.

Apa itu kompensasi lag pada server?

Server menyimpan riwayat posisi pemain sebelumnya dan memundurkan waktu sesaat saat tembakan diproses agar akurat bagi pemain ber-ping tinggi.
