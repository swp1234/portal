1. 두뇌 게임 워크아웃

기억, 논리, 속도, 골고루 중 플레이 초점을 고르고 5분·10분·15분과 에너지 수준을 선택하면 짧은 브라우저 게임 순서를 만듭니다.

  • 선택한 조건에 따라 여러 게임을 한 순서로 제시
  • 각 게임 완료 표시와 연속 이용 기록을 현재 브라우저에 저장
  • 로그인 없이 다시 열어 이전 진행 상태 확인

2. 2048 보드 코치

현재 2048 보드의 16개 칸을 입력하면 위·오른쪽·아래·왼쪽 이동을 모두 시뮬레이션해 합계 점수, 빈칸, 합칠 수 있는 쌍을 비교합니다.

  • 움직일 수 없는 방향을 구분하고 네 방향을 나란히 비교
  • 선택한 방향으로 움직인 직후의 보드 미리보기 제공
  • 빈칸과 모서리 배치 등 사용한 판단 요소를 함께 표시

코치의 추천은 휴리스틱 계산 결과이며 완벽한 수나 승리를 보장하지 않습니다.

3. 뇌 타입 테스트

10개의 짧은 양자택일 질문에 답하면 응답 규칙에 따라 8개 오락용 프로필 중 하나를 결과로 보여줍니다.

  • 각 질문에서 두 선택지 중 하나를 고르는 방식
  • 완료 후 프로필 이름과 선택 패턴 설명 표시
  • 결과를 다시 시작하거나 공유할 수 있는 화면 제공

성격·능력 진단이 아닌 가벼운 자기 탐색용 테스트입니다.

4. 반응속도 테스트

대기 화면이 준비 신호로 바뀐 뒤 누르기까지 걸린 시간을 밀리초(ms)로 표시합니다. 클래식은 5회, 챌린지는 20회 진행합니다.

  • 너무 일찍 누른 경우 해당 시도를 다시 안내
  • 라운드별 시간과 전체 평균을 결과 화면에 표시
  • 개인 최고 기록과 플레이 횟수를 현재 브라우저에 저장

⚡ 시각 신호에 맞춰 탭하기

기기와 브라우저 환경에 따라 지연이 달라질 수 있는 오락용 기록입니다.

반응속도 테스트 열기

5. 색상 기억력

네 색상 버튼이 보여주는 순서를 본 뒤 같은 순서로 누릅니다. 성공한 라운드마다 순서가 하나씩 길어집니다.

  • 라운드 번호와 현재 점수를 화면에 표시
  • 잘못 누르면 결과 화면에서 점수 확인
  • 브라우저에 개인 최고 점수 저장

6. 2048 게임

4×4 보드에서 화살표 키나 스와이프로 타일을 움직이고, 같은 숫자가 맞닿으면 합쳐 점수를 얻는 퍼즐입니다.

  • 현재 점수와 브라우저에 저장된 최고 점수 표시
  • 유효한 이동 뒤 새 숫자 타일 생성
  • 직전 한 단계의 보드로 되돌리는 기능 제공

7. 타이핑 속도

단어 모드와 문장 모드 중 하나를 선택해 화면의 텍스트를 입력하고 WPM과 입력 정확도를 확인합니다.

  • 단어 모드에서 쉬움·보통·어려움 선택
  • 진행 중 남은 시간, WPM, 정확도 표시
  • 최근 WPM·정확도와 최고 WPM을 현재 브라우저에 저장

⌨️ 타이핑 기록 확인하기

단어 또는 문장 방식으로 한 번의 입력 기록을 확인할 수 있습니다.

타이핑 속도 테스트 열기

8. 기억 카드

카드 두 장을 차례로 뒤집어 같은 그림의 짝을 찾고 모든 짝을 맞추면 스테이지가 끝납니다.

  • 쉬움 4×3, 보통 4×4, 어려움 5×4 보드 선택
  • 이모지·동물·과일·국기 카드 테마 제공
  • 점수와 브라우저 최고 기록 표시

9. 지뢰찾기

칸을 열어 주변 지뢰 수를 확인하고 지뢰로 판단한 칸에 깃발을 표시하는 보드 게임입니다.

  • 초급 9×9·지뢰 10개, 중급 16×16·40개, 고급 30×16·99개
  • 남은 지뢰 수와 경과 시간 표시
  • 난이도별 최고 시간을 현재 브라우저에 저장

10. 블록 퍼즐

위에서 내려오는 블록을 이동·회전해 가로줄을 채우는 게임입니다. 다음 블록과 보관한 블록을 별도 영역에서 확인할 수 있습니다.

  • 좌우 이동, 회전, 빠른 내리기, 즉시 내리기 조작
  • 현재 블록을 보관했다가 바꾸는 홀드 기능
  • 점수와 최고 기록을 현재 브라우저에 저장

무엇부터 열어볼까요?

여러 게임을 짧게 이어서 하고 싶다면 두뇌 게임 워크아웃, 현재 2048 판의 다음 수를 비교하고 싶다면 2048 보드 코치가 가장 직접적인 출발점입니다. 한 가지 기록만 확인하려면 뇌 타입, 반응속도, 색상 순서, 타이핑 중 원하는 방식을 고르면 됩니다.

다시 확인: 화면에 표시되는 점수와 프로필은 해당 게임 안의 플레이 결과입니다. 일상 능력의 개선 여부나 건강 상태를 판단하는 자료로 사용하지 마세요.
