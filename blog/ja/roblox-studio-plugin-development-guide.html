多くのRobloxクリエイターがプレイヤー向けゲーム制作に専念する中、開発者向けの開発支援ツール（Studio Plugin）市場で高い収益を上げるエンジニアが急増しています。Roblox Creator Storeでは、自作したStudioプラグインを米ドル（USD）やRobuxで直接販売できます。

商用レベルのプラグイン開発には、通常のゲームスクリプトとは異なる専門APIの習得が不可欠です。Studio画面に格納できるDockWidgetPluginGui、Ctrl+Zによる安全なアンドゥ（取り消し）を保証するChangeHistoryService、選択オブジェクトを制御するSelection APIが基本となります。本ガイドでは開発から販売までの全手順を網羅します。

ツール開発の利点： 5,000人のクリエイターが使うプラグインは、ゲームのような高額なサーバー維持費や運用コストなしで安定した利益をもたらします。

1. Studioプラグインの動作環境とセキュリティ権限

プラグインはStudio内で高い特権を持って動作します:

  • 実行コンテキスト： Studioクライアント側でローカル動作し、階層構造の改変や内部パラメータの編集権限を持ちます。
  • ローカルプラグインでの即時テスト： スクリプトを %localappdata%\Roblox\Plugins に保存すれば、Webへのアップロードなしで瞬時に動作テストが可能です。
  • セキュリティ権限： 外部HTTP通信やスクリプト書き換えを行う場合は、ユーザーの明示的な許可が必要です。

2. DockWidgetPluginGuiによるドッキングパネルUI

エクスプローラーやプロパティのようにStudio画面に馴染むパネル設計:

  • DockWidgetPluginGuiInfoの設定： 初期ドッキング位置（左、右、フローティング）と最小ウィンドウサイズを指定します。
  • StudioThemeの動的取得： settings().Studio.Theme から背景色や文字色を取得することで、ダークモード・ライトモードの両方に美しく調和します。
  • レスポンシブ配置： UIListLayoutを活用し、ウィンドウサイズ変更時にも要素が崩れないように設計します。

3. ChangeHistoryServiceによる安全なアンドゥ処理

初心者が最も陥りやすい落とし穴は、Ctrl+Zの履歴破壊です:

  • SetWaypointの記録： オブジェクトに変更を加えた直後に必ず ChangeHistoryService:SetWaypoint("作業名") を呼び出します。
  • 単一ステップへの統合： 複数処理をまとめ、1回のCtrl+Zでプラグイン実行前の状態に完全に戻せるようにします。
  • Selection APIの連動： Selection:Get() で現在ユーザーが選択しているパーツだけを安全に一括編集します。

4. 実践コード：選択パーツ一括最適化プラグイン

ドッキングUIを表示し、選択されたメッシュの当たり判定と影を一括オフにする完成版スクリプト:

Studioプラグイン完全スクリプト (Toolbar & DockWidget)
local ChangeHistoryService = game:GetService("ChangeHistoryService")
local Selection = game:GetService("Selection")

local toolbar = plugin:CreateToolbar("Optimization Tools")
local button = toolbar:CreateButton("Optimizer", "Open Batch Part Optimizer", "rbxassetid://4458901886")

local widgetInfo = DockWidgetPluginGuiInfo.new(
    Enum.InitialDockState.Float,
    false, false, 260, 180, 200, 140
)

local widget = plugin:CreateDockWidgetPluginGui("BatchOptimizerGui", widgetInfo)
widget.Title = "Mesh Optimizer"

local btnOptimize = Instance.new("TextButton")
btnOptimize.Size = UDim2.new(1, -20, 0, 44)
btnOptimize.Position = UDim2.new(0, 10, 0, 10)
btnOptimize.Text = "選択パーツを一括最適化"
btnOptimize.BackgroundColor3 = Color3.fromRGB(16, 185, 129)
btnOptimize.TextColor3 = Color3.fromRGB(255, 255, 255)
btnOptimize.Parent = widget

button.Click:Connect(function()
    widget.Enabled = not widget.Enabled
end)

btnOptimize.MouseButton1Click:Connect(function()
    local selected = Selection:Get()
    local count = 0
    for _, obj in ipairs(selected) do
        if obj:IsA("BasePart") then
            obj.CastShadow = false
            if obj:IsA("MeshPart") then
                obj.CollisionFidelity = Enum.CollisionFidelity.Box
            end
            count = count + 1
        end
    end
    ChangeHistoryService:SetWaypoint("Optimized " .. count .. " Parts")
end)

コード解説：リボンメニューにボタンを作成し、フローティングパネルを表示。クリック時に選択パーツの影を消し、当たり判定をBoxに変更してUndo履歴を安全に記録します。

無料脳タイプ＆認知診断を受ける

よくある質問 (Roblox Studio プラグイン開発)

公開せずに手元のPCだけでプラグインをテストする方法は？

Studioの [プラグイン] > [プラグインフォルダーを開く] から表示されるローカルフォルダにファイルを保存すれば即座に読み込まれます。

プラグインを米ドルで販売できますか？

はい。本人確認を完了したクリエイターは、Creator Store上で米ドル価格を設定して販売できます。

ChangeHistoryServiceを使用しないとどうなりますか？

プラグインの操作がCtrl+Zで元に戻せなくなり、ユーザーのプロジェクトを破壊する危険があります。

ダークモードとライトモードの両方に対応させるには？

settings().Studio.Theme:GetColor() を使ってシステム標準の色を取得してUIに適用します。
