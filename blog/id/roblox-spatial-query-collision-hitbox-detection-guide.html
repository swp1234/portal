Dalam game pertarungan Roblox, serangan yang meleset padahal terlihat kena (atau sebaliknya) merusak keseruan bermain.

Event lama `BasePart.Touched` tidak dapat diandalkan karena jeda komputasi fisika dan rentan cheat. Game profesional menggunakan Spatial Query dengan `GetPartsInPart` dan `OverlapParams`.

Aturan Emas Hitbox: Jangan gunakan Touched untuk senjata. Gunakan Spatial Query dengan verifikasi jarak di server.

1. Mengapa Touched Gagal dalam Pertarungan Presisi

Kelemahan fisika dan celah eksploitasi:

  • Efek Tunneling: Ayunan pedang yang sangat cepat melompati frame simulasi fisika.
  • Kerentanan Eksploitasi: Klien dapat memicu event Touched palsu.
  • Pemicuan Tak Terkontrol: Puluhan sinyal tabrakan dalam sekejap membebani server.

2. Rangkaian Spatial Query & OverlapParams

Pemeriksaan interseksi geometris instan:

  • GetPartsInPart: Deteksi volume akurat untuk tebasan pedang melengkung.
  • GetPartBoundsInBox: Pengecekan kotak dan bola yang cepat untuk ledakan.
  • OverlapParams: Mengecualikan penyerang dan membatasi part yang diproses.

3. Raycast Hitbox vs Query Spasial Volumetrik

Memilih teknik yang pas untuk tiap senjata:

  • Raycast Hitbox: Sangat cocok untuk pedang dan senjata berbilah tipis.
  • Query Volumetrik: Cocok untuk palu godam, hantaman tanah, dan ledakan AoE.
  • Pendekatan Hibrida: Efek langsung di klien, kerusakan disahkan oleh server.

4. Skrip Lua Produksi: Pengelola Serangan Jarak Dekat

Skrip pertarungan aman dengan validasi jarak:

ServerScriptService.CombatManager
-- Deteksi serangan dengan Spatial Query
local Workspace = game:GetService("Workspace")

Keunggulan: mengecualikan diri sendiri, mencegah hit ganda, dan membatasi jangkauan maks 18 stud.

5. Kompensasi Lag & Pengaman Anti-Cheat

Menjaga keadilan bagi pemain ber-ping tinggi:

  • Buffer Posisi: Server mengecek posisi beberapa saat sebelumnya.
  • Cooldown di Server: Jeda antar serangan dikunci di server.
  • Pengecekan Tembus Dinding: Raycast langsung untuk memastikan tidak ada dinding penghalang.

Pertanyaan Umum (Roblox Spatial Query)

Mengapa GetPartsInPart lebih unggul dari GetTouchingParts?

Bekerja tanpa memandang status CanCollide dan menggunakan filter OverlapParams yang fleksibel.

Bagaimana cara mencegah serangan tembus dinding?

Tembakkan raycast dari penyerang ke target; batalkan serangan jika mengenai rintangan peta.

Bisakah hacker memanipulasi Spatial Query di server?

Tidak, perhitungan di server tidak dapat diakses atau diubah oleh klien.
