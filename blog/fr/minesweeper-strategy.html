Stratégie Démineur : 2 règles pour trouver une case sûre

Commencez par compter autour d’un nombre. Les noms de motifs viennent ensuite : les deux égalités ci-dessous suffisent pour de nombreux premiers coups.

Mis à jour le 1er septembre 2026 · Lecture : environ 5 minutes

Essayez ensuite sur une grille débutant

Dans la version DopaBrain, la première case ouverte et ses huit voisines ne contiennent pas de mine. Dès que les nombres apparaissent, appliquez les deux règles.

Un nombre compte les mines dans les cases voisines

Le chiffre d’une case ouverte indique le nombre total de mines dans les cases qui la touchent horizontalement, verticalement ou en diagonale, au maximum huit. Le chiffre n’est pas lui-même une mine. Sur un bord ou dans un angle, il y a moins de voisines.

Il y a exactement une mine parmi ces huit cases. Les nombres voisins permettent de réduire les possibilités.

Vérifiez ces deux égalités avant de cliquer

1

Toutes les cases fermées sont des mines

Soustrayez du nombre les drapeaux déjà confirmés autour de lui. Si le résultat égale le nombre de cases fermées encore indéterminées, toutes ces cases contiennent une mine.

Nombre − drapeaux = cases fermées → toutes sont des mines

Posez un drapeau seulement quand le comptage le confirme. Un drapeau placé au hasard fausse les étapes suivantes.

2

Toutes les autres cases sont sûres

Si le nombre égale déjà le nombre de drapeaux confirmés qui le touchent, les autres cases fermées autour de ce nombre sont sûres.

Nombre = drapeaux → les autres cases sont sûres

L’ouverture groupée n’est sûre que si les drapeaux sont correctement placés. Sinon, elle peut ouvrir une mine.

Une vérification en quatre étapes

Choisissez un nombre ouvert. Regardez d’abord uniquement les cases qui le touchent.
Comptez les drapeaux et les cases fermées. N’oubliez pas les diagonales.
Testez les deux égalités. Si aucune ne fonctionne, comparez avec un nombre voisin.
Ne jouez que le coup confirmé. Ouvrez une case sûre ou posez un drapeau. Gardez les suppositions pour la fin.

Mini-exercice : quel est le prochain coup ?

Un « 1 » touche déjà un drapeau confirmé. Deux autres cases fermées touchent le même « 1 ». Que faire de ces deux cases ?

Spécificités de DopaBrain et limites du guide

Ce que cette page peut affirmer
  • La sécurité de la première case et de ses huit voisines est propre à la version DopaBrain. Les autres versions peuvent fonctionner autrement.
  • Le bouton indice montre une case non minée encore fermée. C’est une aide de jeu, pas une démonstration du raisonnement.
  • Les mines sont placées aléatoirement après le premier clic. Certains plateaux exigent une supposition : aucune garantie de victoire ou de résolution n’est donnée.
  • La grille, les cases, la victoire ou défaite et le temps ne sont pas envoyés aux événements Analytics.
