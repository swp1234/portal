Membangun map open-world yang luas di Roblox memiliki tantangan besar: lebih dari 60% pemain menggunakan perangkat mobile dengan RAM di bawah 3GB. Memuat seluruh map secara bersamaan akan menyebabkan crash seketika.

Fitur StreamingEnabled memuat dan menghapus objek 3D secara dinamis berdasarkan jarak pemain. Namun, skrip client harus disesuaikan agar tidak mengalami error nil. Panduan ini mengupas tuntas ModelStreamingMode dan RequestStreamAroundAsync.

1. Cara Kerja StreamingEnabled: Radius dan Penghematan RAM

Pengelolaan geometri dunia secara dinamis oleh engine Roblox:

  • StreamingTargetRadius: Jarak maksimum dalam stud tempat objek dimuat dan dirender.
  • StreamingMinRadius: Radius inti yang tidak akan pernah di-unload dalam kondisi apa pun.
  • StreamOutBehavior: Mengosongkan memori dari objek yang jauh saat RAM HP mulai penuh.
  • StreamingPauseMode: Menghentikan fisika secara aman saat kendaraan bergerak sangat cepat.

2. ModelStreamingMode: Mengontrol Replikasi Model

Menjaga keutuhan model interaktif:

  • Default: Bagian dalam model dimuat secara terpisah dan dapat merusak visual.
  • Atomic: Model dan seluruh isinya dimuat atau dihapus sebagai satu kesatuan utuh.
  • Persistent: Selalu ada di memori client sejak bergabung (gunakan hanya untuk area sentral).
  • PersistentPerPlayer: Mengunci model tertentu untuk pemain spesifik melalui server.

local CollectionService = game:GetService("CollectionService")
local Workspace = game:GetService("Workspace")

local TAG_NAME = "InteractiveNPC"

local function onObjectStreamedIn(instance)
    if not instance:IsA("Model") then return end
    
    -- Ensure primary part exists before attaching UI
    local primaryPart = instance.PrimaryPart or instance:WaitForChild("HumanoidRootPart", 5)
    if not primaryPart then return end
    
    print("[Streaming] Interactive object loaded: " .. instance.Name)
    -- Attach billboard prompt or local animation controller
end

local function onObjectStreamedOut(instance)
    print("[Streaming] Interactive object unloaded: " .. instance.Name)
    -- Clean up any active local tweens, highlights, or sound emitters
end

CollectionService:GetInstanceAddedSignal(TAG_NAME):Connect(onObjectStreamedIn)
CollectionService:GetInstanceRemovedSignal(TAG_NAME):Connect(onObjectStreamedOut)

-- Initial sweep for parts already streamed in upon join
for _, obj in ipairs(CollectionService:GetTagged(TAG_NAME)) do
    task.spawn(onObjectStreamedIn, obj)
end

4. Mencegah Jatuh ke Void: RequestStreamAroundAsync

Mengatasi bug karakter jatuh ke jurang saat teleportasi:

  • Bahaya Void: Berpindah sebelum tanah dimuat menyebabkan karakter jatuh tanpa akhir.
  • Permintaan Pre-fetch: Jalankan player:RequestStreamAroundAsync() sebelum memindahkan posisi karakter.
  • Anchor Sementara: Kunci HumanoidRootPart hingga verifikasi tanah selesai dimuat.

5. Manajemen Aset: LOD dan Atlas Tekstur

Kualitas grafis tinggi dengan konsumsi VRAM minimal:

  • Mesh LOD: Atur RenderFidelity ke Performance untuk mereduksi poligon objek jauh.
  • Atlas Tekstur: Gabungkan beberapa tekstur ke lembar 2048x2048 untuk menghemat Draw Calls.
  • Penyederhanaan Medan: Gunakan mesh low-poly untuk latar pegunungan yang tidak terjangkau.

Frequently Asked Questions

Mengapa skrip mengalami error saat StreamingEnabled aktif?

Karena objek yang jauh belum ada di client Workspace sebelum pemain mendekat. Akses langsung menghasilkan nil.

Apa perbedaan antara Atomic dan Persistent?

Atomic menghemat memori dengan menghapus seluruh model saat jauh, sedangkan Persistent tetap berada di RAM selamanya.

Bagaimana StreamingEnabled mencegah crash di HP?

Dengan hanya menyimpan data dalam radius beberapa ratus stud di RAM, menjaga penggunaan memori di bawah 800MB.

Bisakah server mengakses bagian yang di-stream out pada client?

Bisa! Server selalu menyimpan seluruh data Workspace secara lengkap setiap saat.
