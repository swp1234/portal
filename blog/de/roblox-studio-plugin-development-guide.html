Während die meisten Entwickler nur Spiele für Endnutzer bauen, erschließen sich clevere Entwickler einen profitablen Nischenmarkt: Entwicklertools für Studio. Im Creator Store können eigene Plugins gegen echtes Geld (USD) und Robux verkauft werden.

Ein professionelles Studio-Plugin nutzt APIs, die normale Spielskripte nie berühren: DockWidgetPluginGui für andockbare Bedienfelder, ChangeHistoryService für zuverlässiges Undo/Redo (Strg+Z) und die Selection API. Dieser Leitfaden erklärt die Entwicklung von Grund auf.

Tool-Ökonomie: Ein nützliches Plugin mit 5.000 Installationen generiert planbare Einnahmen – ganz ohne Server-Hostingkosten oder Live-Betriebsaufwand.

1. Plugin-Architektur & Sicherheitsmodell

Plugins laufen mit erweiterten Rechten in Studio:

  • Ausführungskontext: Plugins laufen lokal in Studio mit Zugriff auf Instanziierung und Selektion.
  • Lokale Plugins: Speichern Sie Skripte im lokalen Ordner %localappdata%\Roblox\Plugins für sofortiges Testen ohne Web-Upload.
  • Berechtigungen: Externe HTTP-Aufrufe erfordern die ausdrückliche Bestätigung des Nutzers über Sicherheitsabfragen.

2. Dockbare Oberflächen mit DockWidgetPluginGui

Nahtlose Integration in die Studio-Oberfläche:

  • DockWidgetPluginGuiInfo: Legt die Startposition (links, rechts, schwebend) und Mindestmaße (z.B. 260x180 Pixel) fest.
  • StudioTheme-Anpassung: Über settings().Studio.Theme passen sich Farben dynamisch an Dark- und Light-Mode an.
  • Responsive Gestaltung: Nutzen Sie UIListLayout für flexible Skalierung.

3. Sicheres Undo/Redo mit ChangeHistoryService

Der häufigste Fehler bei Plugins ist ein defekter Strg+Z-Verlauf:

  • SetWaypoint setzen: Nach jeder Modifikation sofort ChangeHistoryService:SetWaypoint() aufrufen.
  • Atomare Schritte: Mehrere Transformationen zu einem einzelnen Rückgängig-Schritt zusammenfassen.
  • Selection-Service: Über Selection:Get() gezielt nur die aktuell markierten Teile bearbeiten.

4. Produktionsfertiges Plugin: Batch-Teile-Optimierer

Vollständiges Skript für ein andockbares Optimierungswerkzeug:

Studio Plugin Skript (Toolbar & DockWidget)
local ChangeHistoryService = game:GetService("ChangeHistoryService")
local Selection = game:GetService("Selection")

local toolbar = plugin:CreateToolbar("Optimization Tools")
local button = toolbar:CreateButton("Optimizer", "Open Batch Part Optimizer", "rbxassetid://4458901886")

local widgetInfo = DockWidgetPluginGuiInfo.new(
    Enum.InitialDockState.Float,
    false, false, 260, 180, 200, 140
)

local widget = plugin:CreateDockWidgetPluginGui("BatchOptimizerGui", widgetInfo)
widget.Title = "Mesh Optimizer"

local btnOptimize = Instance.new("TextButton")
btnOptimize.Size = UDim2.new(1, -20, 0, 44)
btnOptimize.Position = UDim2.new(0, 10, 0, 10)
btnOptimize.Text = "Ausgewaehlte Teile optimieren"
btnOptimize.BackgroundColor3 = Color3.fromRGB(16, 185, 129)
btnOptimize.TextColor3 = Color3.fromRGB(255, 255, 255)
btnOptimize.Parent = widget

button.Click:Connect(function()
    widget.Enabled = not widget.Enabled
end)

btnOptimize.MouseButton1Click:Connect(function()
    local selected = Selection:Get()
    local count = 0
    for _, obj in ipairs(selected) do
        if obj:IsA("BasePart") then
            obj.CastShadow = false
            if obj:IsA("MeshPart") then
                obj.CollisionFidelity = Enum.CollisionFidelity.Box
            end
            count = count + 1
        end
    end
    ChangeHistoryService:SetWaypoint("Optimized " .. count .. " Parts")
end)

Funktionsweise: Erstellt einen Button in der Menüleiste, öffnet ein Fenster und optimiert markierte Teile per Klick mit sicherem Undo-Punkt.

Häufig gestellte Fragen (Roblox Studio Plugin Dev 2026)

Wie teste ich Studio-Plugins lokal ohne Veröffentlichung?

Speichern Sie die Datei direkt im lokalen Plugin-Ordner von Studio. Das Plugin lädt sofort automatisch.

Kann man Plugins für echtes Geld verkaufen?

Ja, verifizierte Entwickler können Plugins im Creator Store in US-Dollar bepreisen.

Warum ist der ChangeHistoryService unentbehrlich?

Ohne ihn funktioniert Strg+Z für Plugin-Aktionen nicht, was die Entwicklererfahrung zerstört.

Wie passe ich das Plugin-Design an Themes an?

Über settings().Studio.Theme:GetColor() lassen sich Farben an Dark- und Light-Mode anpassen.
